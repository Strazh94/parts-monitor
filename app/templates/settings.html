Селекторы парсинга сайта

Конфиг каждого конкурента хранится в поле parser_config. Пример структуры: 

{
  "start_urls": ["https://site.ru/catalog/page-{page}"],
  "max_pages": 30,
  "pagination": "page",
  "item_selector": ".product-card",
  "delay_seconds": 1.5,
  "fields": {
    "name":       {"selector": ".title"},
    "article":    {"selector": ".sku"},
    "oem":        {"selector": ".oem"},
    "price":      {"selector": ".price"},
    "old_price":  {"selector": ".old-price"},
    "stock":      {"selector": ".availability"},
    "brand":      {"selector": ".brand"},
    "url":        {"selector": "a", "attr": "href"}
  }
}

Типы движка: http — обычные сайты; playwright — сайты на JavaScript. Тип меняется при добавлении конкурента.

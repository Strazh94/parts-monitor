Site parsing selectors

Each competitor's config is stored in the field parser_config. Example structure: 

{
  "start_urls": ["https://site.ru/catalog/page-{page}"],
  "max_pages": 30,
  "pagination": "page",
  "item_selector": ".product-card",
  "delay_seconds": 1.5,
  "fields": {
    "name":       {"selector": ".title"},
    "article":    {"selector": ".sku"},
    "oem":        {"selector": ".oem"},
    "price":      {"selector": ".price"},
    "old_price":  {"selector": ".old-price"},
    "stock":      {"selector": ".availability"},
    "brand":      {"selector": ".brand"},
    "url":        {"selector": "a", "attr": "href"}
  }
}

Engine types: http — regular sites; playwright — JavaScript sites. The type is set when adding a competitor.
